**Store Remote** — десктопное приложение для безопасной загрузки оригинальных `.ipa` пакетов напрямую с серверов Apple и их установки на iPhone или iPad по USB-кабелю. Программа позволяет в несколько кликов восстанавливать удаленные из App Store банковские клиенты, сервисы и игры без джейлбрейка и слетающих сторонних сертификатов.

---

## Основные возможности

* **Прямая работа с серверами Apple:** Официальная авторизация через ваш Apple ID с полной поддержкой двухфакторной аутентификации (2FA).
* **Двойной поиск (Dual-Search):** Мгновенный поиск по встроенной базе удаленных приложений одновременно с глобальным каталогом App Store.
* **Пакетная установка (Корзина):** Добавление нескольких приложений в очередь для автоматической поочередной загрузки и установки в один клик.
* **Привязка и проверка покупок:** Проверка доступности выбранных приложений для вашего аккаунта и сохранение их в раздел «Мои покупки» без необходимости скачивать файлы на устройство.
* **Безопасность данных:** Все операции выполняются локально на вашем компьютере. Учетные данные передаются исключительно по зашифрованным каналам напрямую в Apple.
* **Автоматические обновления:** Встроенная система доставки обновлений уведомляет о выходе новых версий и устанавливает их в один клик.

---

## Системные требования

1. **ОС:** Windows 10 / 11 (64-bit).
2. **Компоненты Apple:** Установленный **iTunes** или приложение **«Устройства Apple» (Apple Devices)** из Microsoft Store (необходимы для работы системных драйверов USB-соединения).
3. **Подключение:** Оригинальный или сертифицированный USB-кабель. На экране iPhone/iPad необходимо подтвердить запрос **«Доверять этому компьютеру»**.

> **Важное условие Apple:** Серверы Apple разрешают загрузку `.ipa` файла только в том случае, если приложение **ранее уже загружалось** на ваш Apple ID. Если приложение новое для вашего аккаунта, но еще доступно в App Store — начните его скачивание на телефоне (достаточно появления иконки загрузки), после чего оно навсегда закрепится за аккаунтом и станет доступно в Store Remote.

## Установка и начало работы

1. Скачайте актуальный установщик `StoreRemote_Setup.exe` в разделе **[Releases](../../releases)** или через официального Telegram-бота.
2. Запустите программу и авторизуйтесь в своем аккаунте Apple ID через левое меню.
3. Подключите устройство по кабелю и дождитесь появления статуса **«Подключено»**.
4. Для активации лимита установок нажмите **«Активировать ключ»** в боковой панели и введите ваш лицензионный ключ.
5. Выберите нужные приложения через поиск и нажмите на иконку **USB** для одиночной установки или **«+»** для пакетной загрузки через корзину.
